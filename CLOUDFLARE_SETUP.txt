SLEEPYHUB - CLOUDFLARE WORKERS DEPLOYMENT

SleepyHub is a static website deployed through Cloudflare Workers static assets.

1. Keep the website files at the repository root.
2. Worker configuration is stored in wrangler.jsonc.
3. Worker name: sleepyhub
4. Static assets directory: repository root (.)
5. No site build step is required.
6. Keep private credentials, OAuth secrets, API secrets, tokens, .env files,
   .dev.vars files, and backend configuration out of this public repository.
7. Deploy from the repository root with:

   npx wrangler deploy

8. Wrangler uploads the static assets and deploys the sleepyhub Worker.
