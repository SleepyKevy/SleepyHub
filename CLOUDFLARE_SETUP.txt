SLEEPYHUB - CLOUDFLARE WORKERS DEPLOYMENT

SleepyHub is deployed as a Cloudflare Worker with static assets.

1. Keep the website in the SleepyKevy/SleepyHub repository.
2. The Worker configuration is in wrangler.jsonc.
3. Worker name: sleepyhub
4. Static assets directory: repository root (.)
5. Keep private application credentials, OAuth secrets, API secrets, and backend configuration out of this website repository.
6. To deploy from the repository root, use:

   npx wrangler deploy

7. Wrangler uploads the static website assets and deploys the sleepyhub Worker.
8. Future website updates should be committed to GitHub and then deployed with Wrangler unless Cloudflare Git deployment is intentionally configured later.
