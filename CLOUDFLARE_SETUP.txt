SLEEPYHUB - CLOUDFLARE WORKERS DEPLOYMENT

SleepyHub is configured as a static-assets Cloudflare Worker.

1. Open a terminal in the repository root.
2. Confirm Wrangler is authenticated to the intended Cloudflare account.
3. Worker name: sleepyhub
4. Production URL: https://sleepyhub.sleepyservices.workers.dev/
5. Review assets/js/site-config.js before deployment if release links change.
6. Deploy with: npx wrangler deploy
7. After deployment, verify the splash page, Home, Downloads, product pages, Changelogs, Support, GitHub, Privacy, and 404 behavior.
8. Confirm the download buttons point to the intended GitHub release assets before announcing the release.

Do not place OAuth secrets, API keys, tokens, private backend configuration, or other credentials in this website repository.
