PRIVACY

The public website is intentionally separated from private application services and account systems.

Website privacy

This website package is static HTML, CSS, JavaScript, and image files. It does not require access to private application credentials or account configuration.

Separation by design

The website is intended to deploy as its own Cloudflare Pages project and its own GitHub repository. SleepySource and SleepyChat application services remain separate.

Important

  • No private credentials belong in this website repository
  • Private configuration should not be committed
  • Sensitive account information should not be embedded in browser JavaScript
  • Download links should point to official release locations
