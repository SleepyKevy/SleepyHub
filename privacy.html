PRIVACY

The public website is intentionally separated from private application services and account systems.

Website privacy

This website package is static HTML, CSS, JavaScript, and image files. It does not require access to private application credentials or account configuration.

Separation by design

The website is intended to deploy as its own public website. SleepySource and SleepyChat application services remain separate from the public site.

Public release metadata

The Downloads page may request public release metadata from the GitHub API so it can show the current file size and release date. SleepyHub does not send account credentials with that request.

Local browser preferences

SleepyHub stores your selected visual theme in your browser so it stays consistent between pages. The welcome screen also uses session-only browser storage to avoid repeating the same random splash theme back-to-back. Local file previews may use temporary tab state to carry the theme between file:// pages. These preferences do not contain account credentials or personal profile information.

Important

  • No private credentials belong in this website repository
  • Private configuration should not be committed
  • Sensitive account information should not be embedded in browser JavaScript
  • Download links should point to official release locations
