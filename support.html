QUICK ANSWERS

Frequently asked questions

The common stuff, without making you dig through a wall of documentation.

01Do I need both SleepySource and SleepyChat?

No. They are separate standalone apps. Use only the one you want, or run both if they fit your setup.

02Do the apps need an installer?

No installer is required for the current releases. Download the official ZIP, extract it to a normal writable folder, and run the application from there.

03Which streaming platforms are supported?

SleepyChat combines Twitch and Kick chat. SleepySource provides OBS and creator tools, with its connected account and event features currently centered on Kick.

04Where are my settings stored?

The apps keep their local data beside the application in their own data folders. Keep those data folders with the app if you move an already configured copy.

05Why might Windows show a SmartScreen warning?

The current Windows builds are unsigned, so Windows may warn on first launch. Download only from the official SleepyHub links and use the VirusTotal and SHA-256 verification information on the Downloads page.

06What should I include when reporting a bug?

Include the app name and version, what you were doing, what you expected, what actually happened, and any useful error text or safe screenshot. Never post passwords, tokens, client secrets, or private webhook URLs.
