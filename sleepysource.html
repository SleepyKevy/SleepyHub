SLEEPYSOURCE

The full creator-tool side of SleepyHub: streaming overlays, alerts, dashboards, OBS browser-source workflows, and creator utilities.

What SleepySource is

SleepySource is the larger desktop creator toolkit in the SleepyHub ecosystem. It is built around the practical things a streamer needs while setting up and running a broadcast, especially OBS Browser Source workflows and creator-facing controls.

Core areas

  • Stream dashboard and connection status
  • Overlay tools and browser-source output for OBS
  • Alert Studio for stream event alerts
  • Chat Overlay for on-stream chat presentation
  • Now Playing media display tools
  • Countdown and timer utilities
  • Overlay design and customization tools
  • Kick connection / authentication workflows

Who it is for

SleepySource is aimed at streamers who want several useful creator tools in one Windows application instead of piecing together a large collection of separate utilities.
