SleepySource 1.0.0 — Consolidated ReleaseAugust 17, 2026

Release / Packaging

  • Standardized active branding and executable/project metadata to SleepySource 1.0.0 / 1.0.0.0.
  • Updated window, tray, single-instance identity, updater comparison, user-agent, page titles, splash build label, footer, and version fallbacks.
  • Renamed the source build script to BUILD_RELEASE.ps1 and updated its output folder to “SleepySource 1.0.0”.
  • Updated GitHub Windows runtime-smoke workflow naming and replaced pre-release wording with release wording.
  • Added detailed README.txt and consolidated release_notes.txt to Public and Source packages.
  • Public release filename is SleepySource_1.0.0.zip with one top-level “SleepySource 1.0.0” folder.

Navigation / UI

  • Moved Connections out of Tools and made it a standalone main navigation tab directly below Home.
  • Tools now contains Now Playing, Chat Overlay, Alert Studio, Stream Dashboard, and Countdown Pro.
  • Fixed active-state behavior so Connections no longer highlights Tools.
  • Removed stray sidebar separators and tightened tool/accordion spacing.
  • Matched Now Playing, Chat Overlay, Alert Studio, and Countdown Pro bars more closely to the Tools dropdown style.
  • Preserved existing themes, overlays, layouts, and SleepySource branding.

Startup Experience

  • Added the branded WebView2 splash/loading experience with the high-resolution raccoon mark.
  • Added staged progress, ambient particles, cyan/blue lighting, logo sheen, and the final Ready pulse.
  • Dashboard handoff now waits for the C# backend-ready gate.
  • Refined progress interpolation, status crossfades, ambient timing, and the final splash-to-dashboard transition.
Hosted Kick OAuth / SleepyServicesSleepySource 1.0.0

Hosted Connection System

  • Added one hosted Connect with Kick flow shared by Chat Overlay, Alert Studio, and Stream Dashboard.
  • Removed desktop Client ID / Client Secret entry and the legacy saved Kick developer-credential flow.
  • Removed the local Kick OAuth callback, separate Stream Controls authorization, Quick Tunnel runtime usage, trycloudflare.com webhook flow, and manual webhook registration controls.
  • Added hosted OAuth session polling, persistent connection status, managed event subscriptions, realtime WebSocket delivery, and D1-backed reliable queue fallback.
  • Desktop persistence now keeps only the opaque SleepySource connection credential; legacy Kick credential files are removed during migration.
  • Stream Dashboard inherits the shared Kick connection instead of requiring a second authorization flow.

SleepyServices Migration

  • Moved the hosted SleepySource API base to sleepysource-api.sleepyservices.workers.dev.
  • Updated OAuth start/status, API health, persistent connection, realtime, stream proxy, hosted event calls, Worker health/webhook URLs, and deployment docs for the new endpoint.
  • Preserved the Kick redirect path, webhook path, D1 binding, realtime Durable Object binding, and 1.0.0 product identity.
  • Added authenticated Worker proxies for stream metadata, category search, and title/category updates so Kick user tokens stay server-side.
  • System Health now reports hosted API, Kick authentication, event subscriptions, realtime delivery, and D1 fallback status.

Events / Repair

  • Changed hosted Kick event sync into a repair-safe rebuild that removes and recreates SleepySource-managed subscriptions against the current webhook URL.
  • Repair is limited to required SleepySource events and leaves unrelated subscriptions alone.
  • Added managed gifted-Kicks and reward-redemption events alongside chat, follows, and subscription events.
  • Confirmed chat events reach the hosted Worker, realtime/D1 delivery, and Chat Overlay.
  • Declared Workers Logs so invocation logging and dashboard persistence survive future deployments.
  • Removed remaining legacy Workers-account hostname text from packaged source/deployment scripts.
OAuth Hotfix / Branded Connect FlowSleepySource 1.0.0

Fixed

  • Fixed the OAuth-pending JSON contract where OAuthPending could serialize as o_auth_pending while the UI expected oauth_pending.
  • Added an explicit oauth_pending JSON property name and UI compatibility for both property forms.
  • Added status-based polling for authorizing/finishing OAuth states.
  • OAuth completion errors are now surfaced instead of silently disappearing during the handoff.

Branded Connect

  • Added a branded SleepySource /connect/kick page hosted by the Cloudflare Worker.
  • Connect with Kick now opens the SleepySource page first and then continues to Kick.
  • Added branded OAuth success/error pages and hardened callback failure handling so post-approval Worker errors become terminal OAuth failures.
  • Standardized the packaged Cloudflare source filename as worker.js.

Security

  • Kick access and refresh tokens, Client Secret, and token-encryption key remain server-side.
  • Desktop connection credentials use Windows credential protection locally.
  • Kick webhook signatures are verified by the Worker and event subscriptions are managed by the hosted service.
  • Authenticated realtime WebSocket delivery is the fast path with D1 polling + acknowledgement as the reliable fallback.
C# / .NET Application FoundationSleepySource 1.0.0

Core Migration

  • Replaced the transitional Go compatibility backend with in-process C#/.NET 8 services.
  • Removed the SleepySource.Engine.exe runtime dependency.
  • Preserved the WebView2 interface, OBS Browser Source workflow, local service address at 127.0.0.1:17891, portable SleepySource_Data location, and existing route structure.
  • C# services now handle local HTTP/OBS serving, settings/state, profiles/backups, Alert Studio, chat, Countdown Pro, media sessions, hosted Kick bridging, stream settings, health checks, and updates.

Compatibility Fixes

  • Matched legacy API response wrappers and optional/default fields.
  • Fixed alert consumption when an alert has no custom visual or sound media.
  • Fixed backup restore when managed media/profile folders are empty or absent.
  • Preserved countdown font-upload response behavior.

Tools Preserved

  • Now Playing and Overlay Designer behavior retained.
  • Chat Overlay and Alert Studio retained and connected to hosted Kick delivery/events.
  • Countdown Pro and Stream Dashboard retained, with Stream Dashboard using the shared hosted authorization.
  • Profiles, backups, portable data storage, and existing OBS routes retained.

SleepyChat 1.0.0 — Current Build2026

Code Audit / Cleanup

  • Reorganized the C# source into focused App, Backend, Kick, Updates, and Window folders.
  • Split oversized MainForm, HostedKickService, and BackendHost responsibilities into smaller partial files.
  • Extracted WebView CSS and JavaScript from the old monolithic index.html into web/css and web/js.
  • Removed stale bundled Cloudflare Worker/deployment material, obsolete validation/build assumptions, and unused duplicate assets.
  • Updated the build script for the current shared Kick API.
  • Added architecture, shared-backend, and code-audit documentation.
  • Runtime behavior and the public product version remain SleepyChat 1.0.0.

Edge / Theme Render Fix

  • Removed transparent WinForms resize panels that sat over the outside edge of the WebView and exposed the form background on non-blue themes.
  • Manual resizing now uses logic-only edge and corner hit detection with nothing visual layered over the themed UI.
  • Disabled Windows DWM outer-window corner rounding to remove clipped/jagged pixels around borderless window corners.
  • The fix applies across every SleepyChat theme.

Manual Resizing

  • Drag any edge to resize and any corner to resize width and height together.
  • Normal resize cursors remain available.
  • Minimum window size remains 980 × 680.
  • Resize handling disables while maximized.
  • No native Windows caption/frame was restored.

Update Checker

  • The connection-style Updates card remains directly under Kick and Twitch.
  • Status lights remain blue/checking, green/up to date, amber/update available, and red/check failed.
  • Check Now and GitHub controls remain included.

Preserved

  • Working Kick OAuth and Kick chat sending are unchanged.
  • The shared API remains sleepysource-api.sleepyservices.workers.dev.
  • SleepyChat's dark custom title bar remains unchanged.
  • WebView autofill/password-save prompts remain disabled.
  • UI dropdown, spacing, focus, and scrollbar polish remain included.

Verified

  • Windows x64 publish: PASS.
  • Runtime startup: PASS.
  • Kick status/send: PASS.
  • Update checker: PASS.
  • JavaScript and edge-regression checks: PASS.
