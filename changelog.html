SleepySource 1.0.0 — Consolidated ReleaseAugust 17, 2026

The first consolidated release of the current C#/.NET + WebView2 application line, bringing the desktop app, hosted Kick connection system, streamer tools, packaging, and release identity together under SleepySource 1.0.0.

Release highlights

  • Moved the application foundation to in-process C#/.NET 8 and removed the separate SleepySource.Engine.exe runtime dependency.
  • Added the hosted Connect with Kick flow shared by Chat Overlay, Alert Studio, and Stream Dashboard, removing the old desktop Client ID / Client Secret setup.
  • Migrated the hosted API and event flow to SleepyServices with managed Kick subscriptions, realtime WebSocket delivery, and D1 fallback.
  • Repaired Kick event subscription delivery and confirmed chat events reach the hosted Worker and Chat Overlay.
  • Added the branded SleepySource OAuth connect/result pages and fixed OAuth completion/polling edge cases.
  • Moved Connections into its own main navigation tab and cleaned up tool spacing, accordion styling, and sidebar presentation.
  • Added the branded WebView2 splash/loading experience with staged progress, ambient effects, and backend-ready handoff.
  • Preserved Now Playing, Overlay Designer, Chat Overlay, Alert Studio, Countdown Pro, Stream Dashboard, profiles, backups, OBS routes, and portable data storage.
  • Standardized public branding, executable/project metadata, build scripts, package naming, and release documentation to SleepySource 1.0.0.
  • Validated the Windows x64 release, single-file executable, 71/71 HTTP route parity, JSON contracts, persistence/backup behavior, and C# runtime/API smoke tests.

Platform: Windows x64. SleepySource.exe is currently unsigned, so Windows SmartScreen may show a warning on first launch.

SleepyChat 1.0.0 — Consolidated ReleaseAugust 19, 2026

The current consolidated SleepyChat 1.0.0 release keeps the working Kick chat experience intact while cleaning up the C# application structure, fixing themed window rendering, and improving the desktop experience without changing the public product version.

Release highlights

  • Reorganized the C# source into focused App, Backend, Kick, Updates, and Window folders and split oversized responsibilities into smaller partial files.
  • Extracted the WebView CSS and JavaScript from the old monolithic index.html into dedicated web/css and web/js files.
  • Removed stale Cloudflare deployment material, obsolete build assumptions, and unused duplicate assets from the cleaned source tree.
  • Fixed the black square/frame effect on non-blue themes by removing transparent WinForms resize panels from the outside edge of the WebView.
  • Changed manual resizing to logic-only edge and corner hit detection and disabled outer DWM corner rounding for cleaner borderless window edges.
  • Preserved edge and corner resizing, normal resize cursors, the 980 × 680 minimum window size, and maximized-state resize handling.
  • Kept the connection-style Updates card with checking, up-to-date, update-available, and failed status states plus Check Now and GitHub controls.
  • Preserved working Kick OAuth, Kick chat sending, the shared SleepyServices API, custom title bar, disabled WebView autofill/password-save prompts, and existing UI polish.
  • Added architecture, shared-backend, and code-audit documentation for the cleaned source structure.
  • Validated Windows x64 publish, runtime startup, Kick status/send, update checker, JavaScript, and edge-regression checks.

Platform: Windows x64. SleepyChat remains version 1.0.0.
